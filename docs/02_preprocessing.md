# 2. 전처리 · 정규화

## 2-1. 코골이 (마이크)

```
WAV → 16kHz 모노 → 대역통과 50–4000Hz → 바닥소음 추정 → 1초 창(0.5초 이동)
    → 상대 크기(rel_db, peak_db) → 창별 RMS 정규화 → 특징 49개 / 로그 멜 64×101
```

| 단계 | 방법 | 이유 |
|---|---|---|
| 리샘플 | 어떤 샘플레이트든 16 kHz | 모델 입력 통일 |
| 대역통과 | 4차 Butterworth 50–4000 Hz, 양방향(위상 왜곡 없음) | 전원 험·저주파 진동, 고주파 잡음 제거. 코골이 에너지는 대부분 이 안 |
| 바닥소음 | 50 ms 프레임 dB의 하위 10% | 방마다 다른 배경 소음 기준 |
| 창 | 1초, 0.5초 이동 | 코골이 한 번(0.5~2초)을 담고 0.5초마다 판단 |
| **상대 크기** | rel_db = 창 RMS dB − 바닥소음, peak_db = 창 안 최대 프레임 − 바닥소음 | 마이크 거리·게인이 달라도 비교 가능 |
| **크기 정규화** | 창을 RMS = 1로 나눔 | 사람마다 다른 소리 크기 제거 → 음색(모양)만 비교. 크기 정보는 rel_db로 따로 전달 |
| 라벨 정제 | 코골이 녹음 안에서 peak_db < 6 dB 창은 제외 | 숨 사이 조용한 틈까지 '코골이'로 배우는 것 방지 (일관된 라벨) |
| 증강 | 이불 효과(고음 감소), 핑크 잡음, 크기 변화 | 데이터 부족 보완, 이불 덮은 상황 대비 |
| 실시간 | 바닥소음 = 최근 5분 하위 10% (`live.py`) | 밤새 방 소리가 바뀌어도 따라감 |

**코골이 / 아님 판단 기준 (정답 쪽)**: 라벨 구간 안 + 바닥소음보다 6 dB 이상 큰 창 = 코골이. 그 외 라벨 = 아님.

## 2-2. 이갈이 (EMG)

```
µV → 직류 제거 → 노치 60/120/180Hz → 대역통과 20–400Hz → 포화 표시
   → RMS 포락선(100ms, 10ms 간격) → %MVC 정규화 → 버스트 → 에피소드
```

| 단계 | 방법 | 이유 |
|---|---|---|
| 노치 | 60 Hz와 배수 (Q=30) | 한국 전원 잡음 |
| 대역통과 | 20–400 Hz | 20 Hz 아래는 움직임·전극 흔들림. 근전도는 20–400 Hz에 대부분 (SENIAM 권고와 같은 범위) |
| 포화 | 입력 ±403 mV(게인 6)의 98% 이상, 또는 값이 멈춤 | 포화 구간으로 판단·자극하지 않음 |
| 포락선 | 100 ms 이동 RMS | 근육 활동 '세기' |
| **MVC 정규화** | 꽉 물기 보정에서 가장 센 1초 평균 = 100% | 사람·전극 위치·피부 저항 차이 제거. 기준 10 %MVC |
| 대안 | MVC가 없으면 처음 60초 휴식 중앙값의 3배 | 보정 못 했을 때 |
