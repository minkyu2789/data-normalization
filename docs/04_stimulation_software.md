# 4. 자극 소프트웨어 (탐지 → 안전 게이트 → 단계별 진동 → 효과 확인)

> 출력은 **진동 모터(진동 피드백)** 기준으로 완성했다. 전기 자극 출력(변압기 개조 등 자작 회로)은 만들지 않는다.
> 자작 회로로 얼굴·턱에 전류를 주면 화상·경련·심장 쪽 위험이 있고, 세기를 모르는 채로 사람에게 주게 된다.
> 전기 자극이 꼭 필요하면 교수님 확인 + 안전 검토 후 **인증된 저주파 자극기**(세기 제한이 기기 안에 있음)를 쓰고, 이 소프트웨어는 켜고 끄는 신호만 보낸다.

## 4-1. 전체 흐름

```
마이크 ─▶ 코골이 확률(0.5초마다) ─▶ 3회 반복 = 코골이 확정 ─┐
                                                           ├─▶ 안전 게이트 ─▶ 자극 알고리즘 ─▶ 출력
EMG  ─▶ 인과 필터 → %MVC/배경 기준 ─▶ 이갈이 확정 ─────────┘     (통과/보류)     (1~3단계)      ├ 기록만 (기본)
        (위상성: 3번째 버스트 순간 / 긴장성: 2초 넘는 순간)                                     └ ESP32 진동 모터 (--arm)
                                    모든 판단 → decisions.csv,   자극·효과 → stim.csv
```

## 4-2. 안전 게이트 (`trigger/safety.py`)

| 조건 | 기본값 | 의미 |
|---|---|---|
| 무장 | 꺼짐 | 꺼져 있으면 마커만 기록. `--port` + `--arm` + YES 입력 시에만 장치로 전송 |
| 시작 유예 | 20분 | 잠드는 중·전극 안정화 동안 요청 안 함 |
| 확신도 | 0.7 | 코골이: 최근 3번 소리의 평균 확률 / 이갈이: 기준 대비 세기 |
| 신호 품질 | 클리핑 1% 미만, 포화 없음 | 잘못된 신호로 자극하지 않음 |
| 최소 간격 | 60초 | 코골이·이갈이 공통 |
| 최대 횟수 | 시간당 20, 밤당 80 | |
| 무반응 정지 | 연속 3회 후에도 계속되면 30분 쉼 | |
| 비상 정지 | `STOP` 파일, Ctrl+C | 이후 모든 요청 보류, ESP32에 STOP 전송 |

## 4-3. 자극 알고리즘 (`trigger/policy.py`)

| 단계 | 언제 | 진동 패턴 (펌웨어에 고정) |
|---|---|---|
| 1단계 | 처음 요청, 또는 90초 넘게 조용했다가 다시 시작 | 0.2초 × 2번, 약하게 |
| 2단계 | 1단계 후 90초 안에 같은 종류가 다시 요청됨 | 0.3초 × 3번, 중간 |
| 3단계 | 2단계로도 안 멈춤 (더 올라가지 않음) | 0.4초 × 5번, 세게 |

**효과 확인**: 요청 뒤 30초 안에 같은 종류(코골이 소리 / 이갈이 버스트)가 다시 나오면 "안 멈춤". 밤이 끝나면 "30초 안에 멈춘 비율", "단계별 멈춘 비율"을 출력·저장한다(`live_*_stim.csv`). → 레포트의 "자극 효과" 근거.

## 4-4. PC ↔ ESP32 규약 (`trigger/link.py`, `firmware/trigger_receiver`)

```
PC → ESP   TRG,<번호>,<SNORE|BRUX>,<확신도 0~100>,<단계 1~3>*<CRC8>
PC → ESP   HB,<번호>*<CRC8>          1초마다
PC → ESP   STOP*<CRC8>
ESP → PC   ACK,<번호> / NAK,<번호>,<이유>
```

ESP32도 PC를 믿지 않고 따로 검사: CRC, 3초 넘게 HB 없으면 거절·모터 정지, 자체 최소 간격·시간당 최대, 단계 1~3만 허용, 진동 중 새 요청 거절.

**진동 모터 배선**: GPIO → 1kΩ → NPN 트랜지스터(또는 로직레벨 MOSFET) → 모터, 모터 양단에 다이오드. GPIO로 모터를 바로 돌리지 않는다.

## 4-5. 실행

```
python live.py --wav 밤녹음.wav --speed 0 --warmup 0                         # 코골이 → 자극 흐름 (기록만)
python live.py --wav 세션/audio.wav --emg 세션/emg.npy --speed 0 --warmup 0   # 코골이 + 이갈이
python live.py --mic --port COM5 --arm                                       # 실제 진동
```

콘솔 예:
```
[00:01:07]   코골이 확정 → 트리거 보류 (확신도 0.56 < 0.7)
    ◆ 자극 1단계 (진동 0.2초 × 2번, 약하게)
    ◆ [가상 자극 마커] SNORE t=78.5s 확신도 0.80 단계 1
[00:01:18] ▶ 코골이 확정 (6회 반복) → 트리거 #1
[00:03:04] ▶ 이갈이 확정 (위상성, 기준의 23.7배)
    ◆ 자극 1단계 (진동 0.2초 × 2번, 약하게)
자극 효과: 자극 횟수 4, 30초 안에 멈춘 비율 0.0, 1단계 멈춘 비율 0/4
```

(가짜 녹음은 자극에 반응하지 않으므로 멈춘 비율 0은 정상. 실제 사람 시험에서 의미가 있음)

## 4-6. 사람 대상 시험 전에

1. 지도교수님 확인, 학교 IRB 절차 확인
2. 진동 세기는 모터 정격 이내, 피부에 직접 닿는 부분 확인
3. USB로 PC에 연결된 상태에서 몸에 붙은 전극으로 측정할 때는 아이솔레이터 사용
